# Evo Talos SDLC Kit - Release Notes v0.10

**Release Date:** 2026-09-15

---

## Overview

v0.10 keeps the kit aligned with the current release cadence by refreshing the shipped plugin version metadata to 0.10.x and documenting the release in the repo’s release notes index. This release is primarily a versioning and maintenance update that ensures the Codex and Claude plugin manifests reflect the latest published state.

Upgrade is recommended for teams that want the plugin metadata and release documentation to remain synchronized with the current project release line.

---

## Major Features & Changes

### 1. Plugin Version Bump to 0.10

**What changed:**
- Claude plugin manifest version updated to `0.10.0`.
- Codex plugin manifest version updated to `0.10.0`.
- Claude marketplace plugin metadata updated to `0.10.0`.
- Release fingerprint metadata updated to the 0.10 release line.

**Why:**
Version information needs to reflect the latest shipped artifact so install/update tooling, plugin validation, and release tracking stay aligned.

**Impact:**
- Clearer release lineage across Codex and Claude distributions.
- Consistency between installation metadata and the repo’s documented release history.

### 2. Release Documentation Coverage

**What changed:**
- Added release notes at `docs/releases/v0.10.md`.
- Kept the current release-note format consistent with the earlier entries in `docs/releases/`.

**Why:**
Release notes provide a durable record of what changed and make it easier to explain upgrade expectations across projects and toolchains.

**Impact:**
- Easier release tracking and project documentation.
- Better traceability for version-to-version plugin updates.
