# Evo Talos SDLC Kit - Release Notes v0.21

**Release Date:** 2026-11-04

---

## Overview

v0.21 tightens the UI/UX Designer's Figma canvas discipline. The 0.20 placement contract fixed gaps between frames but left two failure modes open: Sections arranged into one very long strip, and screens positioned far outside their parent Section, where they render invisibly. Both are now prescribed rules with lint checks that block handoff in writing modes.

---

## Changes

### 1. `figma-canvas-layout`: Sections on a computed page grid (Rule 4)

- Sections are placed row-major in reading order (US-ID, or phase/task order) on a true grid: every Section in a row shares a top edge, every Section in a column shares a left edge, `1200px` gutters.
- The column count is computed, not chosen: try `C = 1..N`, keep the one whose page aspect ratio is closest to 16:10.
- Page aspect outside 1:3–3:1 with four or more Sections is a blocking `page-aspect` violation. Loose screen frames on the page when Sections are mandatory are a blocking `orphan` violation.
- Within a Section (Rule 3): rows wrap at 8 frames; Section aspect above 4:1 is flagged.

### 2. `figma-canvas-layout`: screens stay inside their Section (Rule 5)

Child `x/y` are parent-local for `SECTION` / `FRAME` parents. Three defect patterns produced out-of-bounds screens: adding the Section's page offset to a child position (double offset), setting `x/y` before `appendChild`, and never resizing the Section after placing children.

- Placement order is now fixed: append to the Section, then set Section-local `x/y`, then fit the Section to its children (160px top padding for the title, 120px elsewhere), then run the page grid.
- The lint checks containment with `absoluteBoundingBox` on both sides. An `out-of-bounds` screen blocks handoff in writing modes; `revise` always fixes it; `incorporate` flags it first in the reconciliation notes without moving human-authored frames.
- `GROUP` is discouraged as a screen container. A Plugin API reference snippet shows the correct order.

### 3. `figma-design-handoff`

- Step 5 handoff gate now names `out-of-bounds` and `page-aspect` alongside overlap.

- Skill-only change; no hook or schema changes. Projects with a vendored copy pick it up on the next `sdlc-init` refresh.
