# Evo Talos SDLC Kit - Release Notes v0.9

**Release Date:** 2026-09-13

---

## Overview

v0.9 focuses on tightening the release workflow and supporting a cleaner upgrade path for existing projects. This release updates the shipped plugin versions to 0.9.x, adds the v0.9 release-note entry under the project’s release docs, and keeps the SDLC kit aligned with the current toolchain expectations for Codex and Claude-based workflows.

Upgrade is recommended for teams tracking release metadata and wanting the latest plugin version stamp reflected in both manifests.

---

## Major Features & Changes

### 1. Plugin Version Bump to 0.9

**What changed:**
- Claude plugin manifest version updated to `0.9.0`.
- Codex plugin manifest version updated to `0.9.0`.
- Claude marketplace plugin metadata updated to `0.9.0`.
- Release fingerprint metadata updated to match the 0.9 release line.

**Why:**
Version metadata should match the current release state so installations and distribution tooling can identify the correct shipped plugin build.

**Impact:**
- Clearer release lineage for plugin install and upgrade checks.
- Improved consistency between plugin manifests and release documentation.

### 2. Release Documentation Coverage

**What changed:**
- Added the release note file at `docs/releases/v0.9.md`.
- Kept the release note structure aligned with the existing documentation pattern used in the repo.

**Why:**
Release notes create a traceable record of what changed and help teams understand upgrade expectations across project versions.

**Impact:**
- Easier project history lookup.
- A consistent place for future version-over-version notes.

---

## Compatibility & Upgrade Notes

- Existing projects can upgrade by reinstalling or refreshing the plugin using the updated 0.9 manifests.
- No breaking SDLC workflow changes are introduced in this release; this is primarily a versioning and documentation update.
- If you maintain local plugin copies, refresh the bundled metadata to ensure the version string stays synchronized.
